# Herrería Klaus — sitio web
Sitio estático listo para GitHub Pages.
- `index.html` — estructura y contenido
- `style.css` — diseño responsive
- `script.js` — filtros y visor de imágenes
- `images/` — logo y fotografías seleccionadas

Publicación: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
